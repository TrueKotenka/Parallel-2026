# Сравнение производительности Merge Sort

Реализованы  две версии алгоритма:
1. Классическая (однопоточная) реализация.
2. Многопоточная реализация с использованием пула `std::thread`.

## Условия тестирования

* **Количество логических ядер процессора:** 12
* **Единицы измерения времени:** Миллисекунды (мс)
* **Тип данных:** Случайно сгенерированные массивы целых чисел (`int`)

## Результаты

| Размер массива (N) | Однопоточная версия (мс) | Многопоточная версия (мс) | Прирост производительности |
|:-------------------|:-------------------------|:--------------------------|:---------------------------|
| **10,000** | 3                        | 3                         | 1.0x (Нет разницы)         |
| **100,000** | 41                       | 12                        | ~3.4x быстрее              |
| **1,000,000** | 405                      | 80                        | ~5.1x быстрее              |
| **10,000,000** | 4345                     | 902                       | ~4.8x быстрее              |

### Итог
Многопоточная сортировка слиянием показывает высокую эффективность на больших наборах данных (от 100 тыс. элементов). Для достижения максимальной производительности рекомендуется комбинированный подход: использование многопоточности для крупных блоков и переключение на классическую однопоточную сортировку для мелких сегментов массива.
