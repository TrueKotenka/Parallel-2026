### Задача 1:
Кто первый захочет обедать (пусть Петя), звонит второму (пусть Вася)

1. Как только Петя пошёл есть - он позвонил Васе.
2. Перед тем как обедать, Вася будет ждать звонка от Пети.
3. После того как Петя пообедал, он звонит Васе.
4. Вася может идти обедать в любой момент, потому что Петя уже поел.

Аналогично наоборот.\
Всегда делаем **2 звонка** - от того, кто первый начал обедать.

Можно договориться, что приоритетом на обед обладает Петя.
Если Петя хочет обедать, и Вася ему не звонил - он идёт есть без звонка.
Как только Петя закончил, он звонит Васе.
Так можно обойтись **1 звонком** в случае, если ест сначала Петя, а потом Вася,
и они не пересекаются. 
Но в остальных случаях будет **2 звонка**.

### Задача 2:

У нас 100 потоков, каждый инкрементирует счетчик 100 раз. Операция `count = count + 1` (разбитая на чтение и запись) не атомарна.

**1. Максимальное возможное значение `count`:**\
**Ответ:** 10 000\
**Обоснование:** Максимальное значение достигается, если ни один поток не помешал другому
как при последовательном выполнении - сначала прочитал, потом прибавил и записал.

**2. Минимальное возможное значение `count`:**\
**Ответ:** 2\
**Обоснование:** Минимальное значение достигается при постоянных перезаписях.

1. Поток 1 читает `count = 0` и засыпает.
2. Поток 2 выполняет 99 итераций, теперь `count = 99`
3. Поток 1 просыпается и записывает единицу, `count = 1`
4. Поток 2 читает `count = 1` и засыпает.
5. В этот момент все остальные потоки выполняют свои операции.
6. Последний оставшийся поток 2 просыпается и пишет `count = 2`

// Структура, описывающая пару танцоров и их примитивы синхронизации
Структура DancePair:
    Событие wink           // Сигнал (подмигивание) от партнера
    Барьер sync(count=2)   // Барьер для одновременного начала и конца танца

// Глобальные переменные для управления очередями
Мьютекс mtx
DancePair ожидающий_ведущий = Пусто
DancePair ожидающий_ведомый = Пусто


Функция dance(sync):
    // Решение задачи 3.2* — гарантия совместного танца
    sync.достичь_и_ждать() // Ждем, пока второй партнер тоже зайдет в функцию
    
    "Танцуем!"      // Оба партнера исполняют танец
    
    sync.достичь_и_ждать() // Ждем партнера, чтобы уйти с танцпола одновременно


Функция leader():
    DancePair partner = Пусто
    need_to_wait = false

    // Блокируем доступ к разделяемым ресурсам
    Захват(mtx)
    Если есть ожидающий ведомый:
        // Нашел ведомого
        partner = ожидающий_ведомый
        ожидающий_ведомый = Пусто
        
        // Подмигиваем партнеру (отправляем сигнал)
        partner.wink.отправить_сигнал()
    Иначе:
        // Партнера нет, встаем в ожидание
        partner = новый DancePair()
        ожидающий_ведущий = partner
        need_to_wait = true
    Освободить(mtx)

    Если need_to_wait == true:
        // Ждем, пока придет ведомый и подмигнет нам
        partner.wink.ждать_сигнала()
    
    // Дождались, идем танцевать!
    dance(partner.sync)


Функция follower():
    DancePair partner = Пусто
    need_to_wait = false

    // Блокируем доступ к разделяемым ресурсам
    Захват(mtx)
    Если есть ведущий (ожидающий_ведущий != Пусто):
        // Нашел ведущего
        partner = ожидающий_ведущий
        ожидающий_ведущий = Пусто
        
        // Подмигиваем партнеру (отправляем сигнал)
        partner.wink.отправить_сигнал()
    Иначе:
        // Партнера нет, встаем в ожидание
        partner = новый DancePair()
        ожидающий_ведомый = partner
        need_to_wait = true
    Освободить(mtx)

    Если need_to_wait == true:
        // Ждем, пока придет ведущий и подмигнет нам
        partner.wink.ждать_сигнала()
    
    // Идем танцевать, дождались!
    dance(partner.sync)
