# C++ Memory Reordering Experiment: x86 vs ARM

Демонстрация аппаратного переупорядочивания доступа к памяти (memory reordering) в многопоточной среде. Эксперимент проводится на языке C++ с кросс-компиляцией и запуском под две архитектуры: **x86_64** и **ARM64** (через QEMU).

## Как запустить

1. Соберите Docker-образ:
   ```bash
   docker build -t memory-test .
   ```
2. Запустите контейнер:
   ```bash
   docker run --rm memory-test
   ```

## Результаты
``` bash
=== Запуск на x86 (Native) ===
Store-Load reordering detected: 0 times out of 500000

=== Запуск на ARM (QEMU) ===
Store-Load reordering detected: 1231 times out of 500000
```

## Суть эксперимента

Программа создает два потока: **thread1** и **thread2**.
1. Изначально в переменных X, Y нули.
2. Первый пишет X = 1 и читает Y
3. Второй пишет Y = 1 и читает X.

При последовательном выполнении хотябы один поток должен прочитать единицу. Используется самая строгая модель память, в результате чего на x86 **не встречается** реордеринг.
Однако на arm очень редко, но **встречается**.
