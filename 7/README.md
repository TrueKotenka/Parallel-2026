# Анализ производительности: влияние кэша CPU на обход матрицы

Профилирование выполнено с помощью Valgrind Cachegrind. (perf что-то не установился)

## Результаты измерений

| Метод суммирования | Время выполнения | Промахи L1 (D1 misses) | Промахи L3 (LLd misses) |
| :--- | :--- | :--- | :--- |
| **По строкам (rows)** | **1.02 сек** | 25.3 млн (1.7%) | 18.8 млн (1.2%) |
| **По столбцам (cols)** | 14.99 сек | 156.6 млн (9.2%) | 111.8 млн (6.6%) |
| **Оптимизированный (opt)** | 2.61 сек | 119.7 млн (7.0%) | **20.1 млн** (1.2%) |

## Анализ метрик

1. **Деградация скорости по столбцам (cols):** Наивный обход по столбцам работает **в ~14.6 раз медленнее**, чем обход по строкам. Причина четко видна в метриках кэша: количество промахов в L1 и L3 кэшах возрастает более чем в 6 раз. Процессор вынужден постоянно выгружать кэш-линии и простаивать в ожидании данных из оперативной памяти.

2. **Эффективность тайлинга (opt):**
   Применение Cache Blocking (тайлинга циклов) для колоночного обхода позволило ускорить выполнение **в 5.7 раз** по сравнению с наивным `cols` (2.61 сек против 14.99 сек). 

3. **Почему работает оптимизация (LLd misses):**
   Главная победа оптимизированного алгоритма кроется в метрике `LLd misses` (Last-Level Data Cache, обычно L3). Количество промахов сократилось с 111.8 млн до **20.1 млн**, что почти в точности равно идеальным показателям построчного обхода (18.8 млн). Блоки данных успешно удерживаются в L3 кэше. 
   *(Промахи L1 кэша остаются выше идеальных из-за накладных расходов на вложенные циклы и необходимости прыгать по памяти внутри самого блока, но доступ к L3 на порядки дешевле доступа к RAM).*

## Вывод
При проектировании алгоритмов обработки больших массивов данных критически важно учитывать архитектуру кэш-памяти процессора. Если бизнес-логика требует неестественного порядка обхода памяти (как в случае колоночного суммирования), применение алгоритмов блочной обработки (Cache Blocking) позволяет драматически снизить нагрузку на RAM и ускорить выполнение в разы.
